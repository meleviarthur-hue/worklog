# 工时

纯本地运行的工时 / 薪资记录，日历式，GitHub 黑线极简风。数据只存在浏览器 localStorage，不联网。

打开：[index.html](minis://workspace/worklog/index.html)

---

## 用法

**点开就是日历**。有记录的日期下方有标记：`■` 白班、`○` 夜班（两个都有就是双班），并显示当天工时。点任意日期进入当天。

**当天页**：列出这天所有班次，点「+ 记录班次」新增，点已有班次可编辑。
新建时**自动填入你在设置里定义的默认时段**，不用每次调时间。

**统计**：本月 / 本周 / 全部切换，显示总工时、白夜班工时、出勤天数、薪资构成、扣款合计、实发。

**设置**：默认班次时段、白班/夜班时薪、加班规则、扣款项、数据导入导出。改完自动保存。

## 默认时段（不用每次改）

设置里给白班和夜班各设一对开始/结束时间，例如：

- 白班 `08:00 – 20:00`
- 夜班 `20:00 – 08:00`

新建班次时，选白班就自动填白班时段，切到夜班立刻换成夜班时段。

## 白夜班分开算

分别在设置里填白班时薪、夜班时薪（夜班一般 1.2~1.5 倍）。
每条班次按所选类型套对应时薪，也可以在单条班次里覆盖时薪。

## 跨零点

结束时间 ≤ 开始时间自动判定为跨零点，按次日算。`20:00–08:00` = 12 小时。

## 加班

设置里定「超过多少小时算加班」和「倍率」。超过部分 × 时薪 × 倍率。
不想算加班费，倍率填 1。

## 扣款项

每条可独立选算法：

| 方式 | 说明 |
|---|---|
| 固定（一次） | 按所选范围只扣一次，如社保 300 |
| 按天 | 金额 × 出勤天数，如餐费 10/天 |
| 按工时 | 金额 × 总工时 |
| 按应发 % | 如个税 3% |

取消勾选「启用」即可停用，不用删除。

## 备份

设置页底部：导出 CSV（Excel 直开，带 BOM 不乱码）、导出/导入 JSON 备份。

> 数据存在本浏览器，清浏览器数据会丢。建议定期导出。
